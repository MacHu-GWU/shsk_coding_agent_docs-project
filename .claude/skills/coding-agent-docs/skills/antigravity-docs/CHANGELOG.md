# Changelog

All notable changes to the `antigravity-docs` skill are documented here.

## [0.2.1] - 2026-07-25

- Antigravity's docs site moved from a client-rendered SPA to a server-rendered Astro app. `content_url` in the manifest is now the doc page URL itself (`https://antigravity.google/docs/<slug>`) — WebFetch it directly, no more separate `/assets/docs/....md` twin.
- Manifest regenerated via `antigravity-docs-index-builder` v0.2.0: richer per-page descriptions (scraped lead paragraph instead of `llms.txt` boilerplate) and finer breadcrumb sections. 77 pages, up from 66.

## [0.1.1] - 2026-07-03

- Initial release.
- Reads a local `references/docs-manifest.json` (generated by `antigravity-docs-index-builder`) and WebFetches each page's `/assets/docs/....md` twin — the workaround for Antigravity's client-rendered doc pages, which have no fetchable page-URL content.
- Small-batch fetch loop: 1–3 pages per batch, evaluate, continue up to a 9-page cap, then ask the user before reading more.
- Treats a 404 on a `content_url` as a stale-manifest signal and points the user to `/antigravity-docs-index-builder`.
